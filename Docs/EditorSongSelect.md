# 에디터 곡 선택 화면

타이틀의 `Editor` 버튼은 `FingerDrum.EditorSongSelect` Scene으로 이동합니다.
이 화면은 별도의 곡 목록 구현을 복제하지 않고 `MusicSelectScene`을
`SongSelectPurpose::Editor`로 생성합니다.

## 공유하는 동작

- `SongCatalog`에서 실제 YMM/YMP 관계를 로드합니다.
- 카테고리, 검색 필드, 곡 정렬 콤보박스, 곡 카드와 펼쳐진 난이도 목록은
  일반 곡 선택 화면과 같습니다.
- 좌우키는 곡, 상하키는 난이도를 이동하며 마우스 선택과 미리듣기도 같습니다.
- Back 또는 Escape는 타이틀로 돌아갑니다.

## 에디터 전용 배치

일반 곡 선택 화면의 왼쪽 기록 패널은 생성하지 않습니다. 곡 정보와 선택한
난이도 정보를 담는 패널이 기존 기록 패널의 왼쪽 경계부터 곡 목록 앞까지
차지합니다. 우측 곡 목록, 상단 카테고리, 검색·정렬, 하단 옵션과 양쪽 버튼은
일반 화면의 반응형 정렬을 그대로 사용합니다.

GO, Enter 또는 Space로 난이도를 확정하면 선택 경로를 기록하고
`FingerDrum.Editor` Scene으로 이동합니다. 악보·실시간 뷰와 타이밍·메타데이터·
이펙트 편집, YMP/YME 저장을 제공합니다. Escape는 미저장 변경의 폐기 여부를
확인한 뒤 에디터 곡 선택으로 돌아갑니다. 다시 진입한 곡 선택은 저장 결과를
카탈로그에서 다시 읽습니다. 자세한 조작은 [ChartEditor.md](ChartEditor.md)를 참고합니다.
