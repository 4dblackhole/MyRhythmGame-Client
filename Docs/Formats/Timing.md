# 유리수 마디·BPM·위치

코드: `Parsing/Submodules/PatternTiming.h`, `MusicalPositionParser.cpp`, `Timing/MusicalTimeline.*`.
검증: `Tests/Rhythm/Submodules/ChartParserTests.cpp`.

## 마디와 위치

최대 100,000마디를 허용합니다. 내부/YMP 명시 위치는 0..99,999,
YME 파일의 마디 번호는 1..100,000입니다. 점·Area 끝점·BPM·마디 길이·편집 입력에
같은 범위를 적용하며, 초과 번호는 큰 배열을 할당하기 전에 오류로 거부합니다.
마지막 마디의 다음 경계(내부 100,000)는 시간 조회용 끝 경계일 뿐 저장 위치가 아닙니다.

`[Time Signature]`와 `[Pattern]`은 각각 독립적인 현재 마디 번호를 가집니다.
`--` 또는 `---` 한 줄을 만날 때 해당 섹션의 현재 마디가 1 증가합니다.
`---`는 마디를 진행하는 것에 더해 바로 다음 마디를 악보의 새 줄 시작 지점으로
기록합니다. 위치 `N/D`는 현재 마디 시작부터 온음표 `N/D`만큼 떨어진 절대
위치이며, `0/1`은 마디 시작입니다.
마디 길이에 다시 `N/D`를 곱하지 않습니다. 예를 들어 `#measure 3/4`인 마디의
`1/2`는 4분음표 두 개 위치입니다. `N`은 `D`보다 클 수 있지만 현재 마디 길이
미만이어야 합니다. 단, `#delay`는 마디 끝과 같은 위치도 허용합니다.
2/4 마디의 3/4처럼 마디 밖에 놓인 노트나 timing 지시문은
경고와 함께 해당 항목만 무시합니다.

```text
[Time Signature]
0/1,#bpm 180
2/4, #delay 25
#measure 3/4
--
#measure C
```

두 마디 구분선은 다음 의미를 가집니다.

| 구분선 | 의미 |
| --- | --- |
| `--` | 현재 마디를 끝내고 다음 마디로 진행합니다. |
| `---` | 현재 마디를 끝내고 다음 마디로 진행하며, 다음 마디를 새 악보 줄의 시작으로 기록합니다. |

예를 들어 다음 `[Pattern]`에서 두 번째 마디는 같은 악보 줄에 이어지고, 세 번째
마디는 새 악보 줄에서 시작하도록 기록됩니다.

```text
[Pattern]
0/4,1,0
--
0/4,2,0
---
0/4,1,0
```

`---`가 `[Time Signature]`와 `[Pattern]`의 같은 마디 경계에 모두 작성되어도
파서는 새 줄 시작 마디를 하나로 합칩니다. 현재 파서는 이 정보를
`PatternDocument::systemBreakMeasures`에 0부터 시작하는 다음 마디 번호로
보존합니다. 에디터 악보 줄바꿈과 메트로놈 루프 초기화는 아직 구현하지 않았으며,
추후 이 값을 사용합니다.

| 지시문 | 의미 |
| --- | --- |
| `N/D,#bpm 값` | 해당 위치부터 BPM을 변경합니다. |
| `N/D,#delay 밀리초` | 해당 위치의 실제 시각을 증감합니다. 양수는 빈 시간을 더하고 음수는 이전 시간 구간을 잘라냅니다. |
| `#measure N/D` | 현재 마디부터 마디 길이 비율을 변경합니다. 예: `3/4`. |
| `#measure C` | 현재 마디부터 기본 `4/4` 길이로 되돌립니다. |

쉼표 앞뒤 공백과 명령·값 사이의 연속 공백은 무시합니다. 분수 내부에는 공백을
넣을 수 없으며 `#`와 명령, 명령과 값은 각각 정확히 붙이거나 띄워야 합니다.

| 문구 | 결과 |
| --- | --- |
| `1/2, #bpm 150` | 허용 |
| `1/2,        #bpm   150` | 허용 |
| `1/ 2, #bpm 150` | 오류 |
| `1/2, #bpm150` | 오류 |
| `#measure 4/4` | 허용 |
| `#measure C` | 허용 |
| `#measure4/4` | 오류 |
| `# measure 4/4` | 오류 |
| `#measure 4/  4` | 오류 |

동일 위치의 BPM은 마지막 선언이 적용됩니다. BPM, 마디 길이, delay와
`Pattern Offset`은 패턴을 불러올 때 정수 마이크로초로 한 번 컴파일됩니다.
마디 길이, 노트 위치, BPM 변경 위치와 subdivision은 64비트 유리수로 누적하고,
BPM 구간별 시간을 계산할 때만 부동소수점으로 변환합니다. 각 노트는 자신보다
앞선 마지막 BPM 변경점의 누적 시간에서 남은 유리수 위치만큼을 더해 계산합니다.
기존 YMP의 화면·음향 효과 지시문은 읽을 때 경고만 내며, YME로 옮기는 대상입니다.

## delay와 잘린 시간 구간

`#delay`의 값은 숫자 ms이며 `ms` 접미사를 붙이지 않습니다. 마디 중간에서도 허용하고,
마디 경계의 길이 증감은 앞이 열린/끝이 닫힌 마디에 속합니다. 이전 마디의 끝 위치와
다음 마디의 `0/1`은 같은 시간 기준점입니다. 원본 `#measure`, BPM, 노트, YME의 마디/박자
유리수는 바꾸지 않습니다. 저장하거나 delay를 제거해도 원본 위치가 복원됩니다.

음수 delay는 새로운 시각부터 지시 직전 시각까지의 이전 구간을 무효화합니다.
그 구간의 일반 노트·틱·BPM·delay·YME 지점 명령/히트사운드 변경은 플레이/표시/예측에서
제외하고, 지시 자신의 위치에 있는 새 노트·BPM·효과는 유지합니다. 무효화된 BPM/delay가
있다면 그 이전의 유효한 BPM 상태를 복원합니다. 저장 원본을 삭제하는 동작은 아닙니다.

롱노트와 YME Area의 시작/끝은 각각 원래 계산된 us 시각을 유지합니다. 끝 시각이
시작보다 **앞설 때만** 롱노트/Area 전체를 제외하고, 같으면 유지합니다. 끝점을 잘린
경계로 옮기지 않습니다. Area 보간의 `u`는 이렇게 계산된 실제 경과 us를 사용하며,
길이가 0이면 그 시각부터 `To`가 적용됩니다. 틱은 일반 노트와 같은 무효 구간 규칙을
사용하고, 자동 연타 수가 0이 된 유지 롤은 기존 양수 계약에 맞게 최소 1회를 요구합니다.

예: Base BPM 120, 기본 4/4에서 두 번째 마디의 `1/4,#delay -1500`은 3/4 온음표에
해당하는 시간을 잘라냅니다. 표시 길이는 첫 마디 2/4(0~1000ms), 두 번째 마디
3/4(1000~2500ms), 다음 마디 4/4가 됩니다. 두 번째 마디의 `1/4` 노트는 1000ms인
표시 마디 시작에 놓이지만 파일에는 여전히 두 번째 마디 `1/4`로 저장합니다.

`MusicalTimeline`은 원본 좌표용 유리수 prefix, 끝점의 기존 시각, 살아남은 BPM 기준점,
무효 구간과 표시 마디 범위를 따로 컴파일합니다. 일반 위치의 유효성 조회는 구간
이진 검색을 사용하고, 완전히 잘린 마디는 플레이 마디선에서 제외합니다. 틱 개수는
제외된 틱들을 생성하지 않고 인덱스 구간으로 계산합니다. 프레임마다 BPM을 적분하지 않습니다.
